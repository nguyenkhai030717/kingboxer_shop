KINGBOXER - PHP + MYSQL XAMPP
1. Giai nen vao C:\xampp\htdocs\kingboxer_shop
2. Start Apache va MySQL trong XAMPP.
3. Mo http://localhost/kingboxer_shop/install.php
4. Tao admin email va mat khau, database mac dinh kingboxer, user root, password de trong neu XAMPP mac dinh.
5. Xoa install.php sau khi cai dat.
6. Dang nhap tai http://localhost/kingboxer_shop/index.php?page=login
7. Them san pham va tai nhieu anh tai trang Quan tri.
Luu y: ban nen tang local de thu nghiem. COD va tao don hoat dong co ban. Chuyen khoan can tu xac nhan. PayPal moi la lua chon, chua tich hop API thu tien. Chua nen dua len internet de nhan don that truoc khi kiem thu bao mat va hoan thien cac tinh nang.
